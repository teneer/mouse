# 에셋 관리 안내

전체 사용자 첨부 에셋과 정확한 파일 수·해상도·배치 상태는 `../docs/ASSET_CATALOG.md`를 기준으로 한다.

## 현재 저장소 상태
- 사용자 첨부 사운드 9개: `assets/audio/`에 복사 완료
- 사용자 첨부 이미지 ZIP 3개: 원본 파일을 확인했으나 개별 PNG를 저장소에 배치하지 않음
- 성장 배경/스프라이트: `assets/visuals/` 배치 예정
- 아바타: `assets/avatars/` 배치 예정
- 클래스123 복원용 이미지와 캡처: 레거시 참조 경로로 분리 보존 예정

원본 ZIP을 보존하고, 에셋을 배치할 때 파일명·해상도·용도를 manifest로 기록한다.
