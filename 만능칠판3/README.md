# 만능칠판 3 — 통합 전자칠판

이 폴더는 원본 `만능칠판2`와 `학급온도계-6`의 **런타임 경로에 의존하지 않는 별도 복사본**입니다.

## 실행
정적 HTTPS 서버 혹은 localhost에서 `만능칠판3/index.html`에 접속합니다. 파일을 직접 여는 `file://` 방식은 원본 전자칠판의 ES 모듈/IndexedDB 때문에 지원되지 않습니다. GitHub Pages/Netlify 등에서 해당 폴더를 공개 디렉터리로 배포할 수 있습니다.

## 구조
- `index.html`, `shell.css`, `shell.js`: 토글 가능한 화면 분할, 드래그 및 키보드 조절, 설정 저장
- `board/`: 만능칠판2 원본의 실행 파일 복사본
- `score/`: 학급온도계-6 원본의 실행 파일과 MP3 복사본. style.css에 좁은 화면 대응 규칙만 추가

## 동작
기본은 칠판 전체 화면이며 '학급 점수판 열기' 버튼으로 우측 패널을 표시합니다. 처음 열면 칠판 70%, 점수판 30%입니다. 경계를 마우스/터치로 드래그하거나 포커스를 맞춘 뒤 방향키(2% 단위, Shift 10%, Home/End)로 조절합니다. 열림 여부와 비율은 localStorage에 저장됩니다. 두 iframe은 닫을 때 파괴하지 않아서 진행 중인 편집 상태를 유지합니다. 서로 다른 프레임이라 스타일 및 일반 단축키 이벤트가 충돌하지 않습니다.

## 저장/호환성과 주의 사항
원본 IndexedDB 및 localStorage의 DB 이름/키를 변경하지 않았습니다. **같은 도메인에서 원본과 신규 앱을 동시에 사용하면 데이터 영역을 공유할 수 있습니다.** 최초 사용 전에 원본 칠판에서 JSON 백업을 저장하세요. 패널 레이아웃만 `whiteboard3.layout.v1`에 별도 저장됩니다. 점수판 저장/동기화의 원본 동작은 그대로 유지합니다.

## 의존성
칠판 HTML은 원본과 같이 Fabric.js 5.3.1을 cdnjs CDN에서 로드합니다. 그러므로 완전 오프라인 실행은 아직 지원하지 않습니다. 기타 앱 코드, CSS, 점수판 음향 파일은 이 폴더 내에 있습니다.

## 검증 상태
코드와 원본 자산 복사 여부는 GitHub 트리로 확인할 수 있습니다. 실제 브라우저에서 필기, 텍스트, 저장/불러오기, 점수 변경, 소리 재생, 좁은 패널에서의 모달, 포인터 이벤트를 별도로 수동 검증해야 합니다. 이 검증 전에는 완성/통과 판정하지 않습니다.
