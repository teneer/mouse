# 브라우저 QA 체크리스트

2026-11-17 GitHub Pages의 초기 골격에서 Chrome으로 기본 동작을 확인했다. 전자칠판 필기, 모드 왕복 후 실행 취소 활성 상태 유지, 네 모드 전환, 체크리스트 항목 추가 및 체크, 점수판에서 다른 탭의 성장 화면에 점수 팝업 표시 및 별길 갱신, JSON 백업 생성을 확인했다. 만능칠판의 기존 자동화 테스트 77개가 통과했다.

## 1. 실행
- [ ] HTTPS 또는 localhost에서 정상 로드
- [ ] 콘솔 오류 없음
- [ ] CSS/JS/이미지/오디오 404 없음
- [ ] 새로고침 후 정상 재진입
- [ ] 1366×768, 1920×1080, 태블릿/모바일 폭에서 레이아웃 확인

## 2. 모드 전환
- [ ] 전자칠판 / 점수판 / 학급 성장 / 체크리스트 전체 화면 전환
- [ ] 분할 화면·우측 점수 패널이 나타나지 않음
- [ ] 모드 전환 후 선택/편집 상태가 안전하게 처리됨
- [ ] 앱 셸의 전역 팝업이 모든 모드 위에 표시됨

## 3. 전자칠판
- [ ] 필기·형광펜·지우개·선택·이동·텍스트
- [ ] 실행 취소/다시 실행
- [ ] 페이지 추가·이동·삭제·순서
- [ ] 이미지/PDF 가져오기와 배치
- [ ] 저장·새로고침 후 복원
- [ ] 기존 6.0 기능 회귀 확인
- [ ] 숨긴 점수판 iframe/패널이 불필요한 데이터 동작을 일으키지 않음

## 4. 점수판
- [ ] 학생 명단 붙여넣기(헤더 포함/미포함, 쉼표/탭)
- [ ] 중복 번호·중복 학생명 처리
- [ ] 학생 선택/해제/다중선택
- [ ] 개인 점수 +/−, 사유 기록
- [ ] 모둠 합계가 구성원 점수 변경과 일치
- [ ] 명단 수정·삭제·복원(구현 후)
- [ ] 점수 이력과 정정(구현 후)

## 5. 학급 성장
- [ ] 1~9개 기여의 진행 상태
- [ ] 10번째 기여에서 학급 점수 정확히 +1
- [ ] 같은 전환 이벤트가 중복 처리되지 않음
- [ ] 감점·직접 조정·되돌리기 정책과 실제 결과 일치
- [ ] 새로고침 후 성장 상태와 시각화 일치
- [ ] 별길·알·나무 에셋 및 사운드 정상 로드

## 6. 체크리스트
- [ ] 날짜 이전/다음 이동
- [ ] 체크/기호/등급/숫자 입력 저장
- [ ] 새로고침 후 입력 보존
- [ ] 체크 해제 시 보상 처리 정책 준수
- [ ] 보상 점수가 한 번만 지급
- [ ] 다른 탭의 수정이 반영
- [ ] 항목 수정/삭제/권한(구현 후)

## 7. 탭 간 연동과 피드백
- [ ] 두 개 이상 탭에서 앱 실행
- [ ] 탭 A에서 점수 변경 시 탭 B DB/화면 갱신
- [ ] 탭 B가 다른 모드여도 공통 팝업 표시
- [ ] 팝업 큐가 연속 이벤트를 누락하지 않음
- [ ] 소리 재생이 브라우저 자동재생 정책에 안전하게 대응
- [ ] 동일 이벤트의 중복 수신 방지

## 8. 백업/복원
- [ ] 모든 store 데이터가 JSON 백업에 포함
- [ ] 새 DB에서 복원 후 학생·모둠·점수·성장·체크리스트 일치
- [ ] 잘못된 JSON에서 기존 DB가 손상되지 않음
- [ ] 구버전/부분 백업에 대한 안내와 처리
- [ ] 복원 시 다른 탭 충돌 방지
