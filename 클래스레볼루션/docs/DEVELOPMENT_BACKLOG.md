# 개발 과제 및 우선순위

기준일: 2026-11-16. 현재 코드를 실제 브라우저에서 검증한 후 순서를 조정한다.

- [ ] `클래스123 복원프로젝트.zip`은 레거시 아바타와 화면 캡처를 분리 보관
- [ ] ZIP 원본을 보존하고, 이미지 파일 수·해상도·경로 manifest 작성
- [ ] 현재 `growth.js` 참조 경로인 `assets/visuals/bg-class-clouds-way.png` 및 `assets/visuals/sp_board_sky_village.png` 확인
- [ ] 현재 `scoreboard.js` 참조 경로인 `assets/avatars/220/avatar_NNN_220.png` 확인
- [ ] 스프라이트 시트 프레임 좌표를 확인하고 애니메이션/아이콘 매핑표 작성
- [ ] 모든 이미지 404, 투명도, 종횡비, object-fit 확인

### P0.2 앱 실행 및 전자칠판 회귀 검증
- [ ] HTTPS 또는 localhost에서 `클래스레볼루션/index.html` 실행
- [ ] 콘솔 오류·누락 리소스·모듈 import 경로 확인
- [ ] 네 모드 전체 화면 전환 확인(분할 화면 금지)
- [ ] 전자칠판 필기·지우개·선택·이동·텍스트·이미지/PDF·페이지·저장 확인
- [ ] 6.0 내부 점수판 패널이 중복 노출되지 않는지 확인
- [ ] 전자칠판을 다시 열거나 모드 전환할 때 캔버스 상태가 유지되는지 확인
- [ ] 원본 폴더의 파일이 수정되지 않았는지 확인

### P0.3 다중 탭·백업
- [ ] 같은 브라우저에서 두 탭을 열고 학생 점수 변경이 양쪽에 반영되는지 확인
- [ ] 다른 모드에 있는 탭에도 팝업 피드백이 나타나는지 확인
- [ ] 같은 이벤트가 중복 팝업/중복 점수 처리되지 않는지 확인
- [ ] 새로고침/브라우저 재시작 후 데이터 유지
- [ ] JSON 백업 후 초기화된 DB에 복원해 데이터 일치 확인
- [ ] 잘못된 JSON, 구버전 백업, 빈 배열, 부분 데이터 처리 정책 정리
- [ ] 복원 도중 다른 탭이 열려 있을 때의 충돌 처리

### P0.4 점수 정책 확정
- [ ] 개인 점수와 학급 성장 점수의 공식 확정
- [ ] 개인 감점이 대기 중 성장 기여를 차감하는지 확정
- [ ] 학급 점수 직접 조정/초기화/되돌리기 정책 확정
- [ ] 모둠 점수가 개인 점수 합계인지 별도 점수인지 확정
- [ ] 레거시 수식과 현재 구현의 차이를 사용자에게 설명하고 결정 받기

## P1 — 점수판을 실제 수업에 사용할 수준으로 완성

### 학생·모둠 관리
- [ ] 학생 추가·수정·삭제·숨김·복원·휴지통
- [ ] 명단 붙여넣기: 헤더 자동 인식, 번호 자동 부여, 탭/쉼표/줄바꿈, 중복 감지
- [ ] 학생 번호·이름·모둠·아바타 편집
- [ ] 모둠 생성·이름 변경·삭제·순서 변경·학생 이동
- [ ] 모둠별 점수와 학생 개인 점수의 동기화
- [ ] 전체선택·선택반전·다중선택 및 선택 상태 UX
- [ ] 70종 아바타 선택 UI 및 220/400 해상도 용도 구분

### 점수 입력·이력
- [ ] 점수 사유 최근 목록·즐겨찾기
- [ ] 임의 점수 입력(현재 +1/-1/+3 고정 버튼 외)
- [ ] 개인/모둠/학급 점수 직접 조정
- [ ] 점수 변경 이력 화면, 날짜·대상·사유 검색/필터
- [ ] 실행 취소/정정과 원본 이벤트 보존
- [ ] 빠른 연속 입력 시 중복/순서/피드백 확인

### 학급 성장
- [ ] 별길·황금 알·나무·마을 에셋의 실제 연결
- [ ] 기여 학생 표시와 성장 단계 애니메이션
- [ ] 10개 기여가 학급 점수로 변환되는 전환 연출
- [ ] 성장 목표·보상 설정과 달성 팝업
- [ ] 교사 직접 조정과 학생 기여 기록의 일관성

## 완료 판정 원칙

- 화면이 렌더링된다는 것만으로 완료 판정하지 않는다.
- 핵심 시나리오를 실제 브라우저에서 실행하고 결과를 기록한다.
- 데이터 보존, 다른 탭 반영, 백업/복원, 원본 전자칠판 회귀를 통과해야 한다.
