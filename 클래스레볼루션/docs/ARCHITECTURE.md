# 현재 코드 구조와 데이터 흐름

## 1. 화면 구조

`클래스레볼루션/index.html`이 앱 셸이다.

- 상단 모드 메뉴: 전자칠판 / 점수판 / 학급 성장 / 체크리스트
- 각 모드는 전체 화면 패널로 전환한다.
- 전자칠판은 `modules/whiteboard/index.html`을 iframe으로 로드한다.
- 점수판·성장·체크리스트는 각각 모듈 함수가 해당 DOM 루트에 화면을 그린다.
- 전역 팝업은 앱 셸 최상단 `#global-feedback`에 표시한다.

분할 패널이 아니라 모드 전환 구조를 유지해야 한다.

## 2. 데이터베이스

파일: `core/db.js`  
DB 이름: `ClassRevolutionLocalDB`  
현재 DB 버전: `1`

| Object store | 키 | 용도 |
|---|---|---|
| classes | id | 학급 기본 정보 |
| students | id | 학생 번호·이름·모둠·아바타·점수 |
| groups | id | 모둠 정보 |
| scoreEvents | id | 개인 점수 변경 이력 |
| growthStates | classId | 학급 점수·대기 기여·누적 기여 |
| growthConversions | id | 학급 점수 전환 이력 |
| checklistDefinitions | id | 체크리스트 항목 정의 |
| checklistEntries | id | 날짜·학생·항목별 기록 |
| settings | key | 앱 설정 |

기본 학급 ID는 `class-default`다. 아직 다중 학급 전환 UI는 없다.

## 3. 탭 간 이벤트

파일: `core/events.js`

- BroadcastChannel: `class-revolution-events-v1`
- localStorage 보조 키: `class-revolution:last-event.v1`
- 이벤트에 고유 ID를 붙이고 이미 처리한 이벤트는 중복 전달을 막는다.
- 점수 변경, 성장 점수 전환, 체크리스트 갱신 등을 다른 탭에 전달한다.
- 전역 피드백 모듈은 앱 셸에 한 번 장착되어 모든 모드에서 팝업을 표시하도록 구성했다.

검증 필요: 탭 간 이벤트는 상태 데이터 자체를 전송하는 것이 아니라 변경 알림이다. 각 모듈이 DB를 다시 읽어 화면을 갱신하는 방식이다.

## 4. 점수 처리

파일: `core/score-engine.js`

`applyIndividualScore`는 IndexedDB 트랜잭션에서 다음을 함께 처리한다.
1. 학생 점수 갱신
2. `scoreEvents` 이력 추가
3. 성장 상태 갱신
4. 기여 10개가 되면 학급 점수 +1 및 `growthConversions` 기록

현재 구현의 가정:
- 개인 양수 점수 1점당 성장 기여 1개
- 대기 기여 10개마다 학급 점수 1점
- 개인 감점은 기존 대기 기여를 차감하지 않음
- 모둠 점수는 해당 모둠 학생 개인 점수 합계로 화면에서 계산

이 가정은 최종 정책이 아니다. `docs/DEVELOPMENT_BACKLOG.md`에서 레거시 공식과 차이를 확인한다.

## 5. 모듈 책임

### 점수판 — `modules/scoreboard.js`
- 학생과 모둠 읽기
- 번호순 학생 카드 표시
- 카드 다중 선택
- 사유 입력
- 현재 +1, -1, +3 빠른 점수 버튼
- 모둠별 개인 점수 합계 표시
- 명단 붙여넣기 시 모둠 이름을 보고 모둠 레코드 생성

미구현: 학생 수정·삭제·복원, 모둠 편집, 점수 사유 즐겨찾기, 점수 이력 UI, 점수 직접 조정·되돌리기.

### 학급 성장 — `modules/growth.js`
- 성장 상태 및 학생 아바타를 읽는다.
- 10개의 별길 위치에 기여 학생을 표시한다.
- 10번째 기여가 도착하면 전환 이벤트를 표시한다.

미구현: 실제 에셋 연결, 별길/나무 단계 애니메이션, 전환 연출 완성, 목표 설정·보상 관리, 교사 직접 조정.

### 체크리스트 — `modules/checklist.js`
- 날짜별 학생 행과 항목 열 표시
- 체크 / 기호(○·△·×) / 1~5 / 숫자 입력
- 체크 항목의 `rewardPoints`가 양수면 최초 체크 시 개인 점수 보상

미구현: 항목 수정·삭제·순서 변경, 템플릿, 권한, 통계, 전체/개별 기간 보기, 보상 취소 정책.

### 전역 피드백 — `core/feedback.js`
- 점수 변경·학급 성장 전환·체크리스트 보상·목표 달성 팝업
- 점수/성장/체크리스트/성공 효과음 연결
- 이벤트 큐 방식으로 연속 팝업 표시

## 6. 백업과 복원

- `exportAll`은 모든 Object store를 하나의 읽기 트랜잭션으로 읽어 JSON에 담는다.
- `importAll`은 DB 이름, 스키마 버전 및 전체 store의 배열을 확인하고 하나의 트랜잭션에서 교체한다. 잘못된 키나 중복 키가 있으면 복원을 취소한다.
- 정상 복원 뒤 `data.restored` 이벤트로 열린 탭이 화면을 갱신한다.
- 복원은 해당 버전의 전체 백업을 대상으로 한다. 부분 복원, 병합, 복원 전 자동 백업은 후속 기능이다.

## 7. 전자칠판 통합

- 전자칠판 복사본은 독립 폴더에 존재한다.
- 클래스레볼루션에서는 기존 6.0의 우측 점수판 분할 패널을 숨기고 앱 셸 메뉴로 모드를 전환한다.
- 원본 전자칠판의 IndexedDB/localStorage 키가 기존 앱과 충돌하는지, 클래스레볼루션 안에서 독립 데이터로 작동하는지 확인해야 한다.
- 원본 6.0의 기존 기능과 저장 동작을 회귀 테스트해야 한다.
