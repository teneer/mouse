    만능칠판 사용 안내

    칠판 기본

    1. 펜·형광펜·텍스트로 칠판에 쓰고, 현재 색상이나 크기를 눌러 설정합니다. 지우개로 획이나 개체를 지웁니다.
    2. 선택 모드에서 개체를 클릭해 옮깁니다. 빈 곳에서 드래그하거나 Shift를 누른 채 클릭하면 여러 개체를 선택합니다.
    3. 이동 모드에서 칠판을 끌어 이동합니다. 마우스 휠이나 ＋/−로 확대하고, 홈 버튼으로 기본 위치와 배율로 돌아옵니다.
    4. 툴바 가장자리 화살표를 누르거나 툴바를 좌우로 드래그하면 숨은 도구를 볼 수 있습니다. 개체 우클릭으로 복사, 그룹, 순서 조정 등의 메뉴를 엽니다.

    페이지·자료

    1. 현재 쪽 / 전체 쪽 버튼을 눌러 썸네일을 엽니다. 양옆 화살표는 이전·다음 쪽으로 이동합니다. 목록 끝의 ＋로 페이지를 추가하고, 썸네일의 … 메뉴에서 이름 변경·복제·삭제를 합니다. 여러 쪽을 다루려면 선택을 누른 뒤 쪽을 체크하고 묶음 이동·이름 편집·삭제를 합니다.
    2. 이미지나 PDF를 칠판에 끌어 놓거나 더 보기 → 이미지·PDF에서 엽니다. 자료는 바로 배치됩니다. 함께 넣은 자료의 배열과 배경 고정은 우클릭 → 세트 속성에서 바꿉니다. 원본이 없는 기기에서도 점선 틀을 선택해 옮기거나 칠판에서 삭제할 수 있습니다.
    3. 원본을 보려면 더 보기 → 파일 관리에서 받습니다. 배경에 고정한 개체는 고정개체 관리에서 고정을 해제한 뒤 편집합니다.
    4. 페이지 편집은 자동저장됩니다. 다른 브라우저로 옮기거나 별도로 보관하려면 더 보기 → JSON 백업을 사용합니다.

    정답 가리개

    1. 지우개 왼쪽의 가리개를 켠 뒤 범위를 드래그합니다. 켜져 있는 동안 연속으로 만들 수 있으며, 버튼을 다시 누르거나 Esc로 종료합니다.
    2. 영역을 클릭하면 답을 보이거나 가립니다. 이름이나 번호는 가려진 영역 한가운데에 표시됩니다. 가리개를 우클릭하면 이름을 바꿀 수 있습니다.
    3. 가리개는 실제로 보이는 부분이 겹치는 맨 위 개체에 붙습니다. 개체를 옮기거나 크기를 바꾸면 함께 움직입니다. 가리개만 다른 개체 위로 옮겨 다시 붙일 수 있습니다. 개체를 배경에 고정하면 연결이 풀립니다.
    4. 왼쪽 체크는 이 페이지의 가리개 열림 상태를 탭끼리 공유합니다. 오른쪽 아이콘은 전부 닫혀 있으면 모두 열고, 하나라도 열려 있으면 모두 닫습니다.

    점수판·추격자

    1. 하단 툴바에서 점수판을 열고 학급이나 모둠의 ＋/−로 점수를 조정합니다. 여러 모둠을 선택한 뒤 아래 조작 바에서 점수를 한꺼번에 반영할 수 있습니다.
    2. 잘못 입력했다면 점수 안내 옆 취소를 누르세요. 연속으로 준 점수가 한 번의 변경으로 묶였으면 표시된 합계가 되돌아갑니다.
    3. 점수판 설정 → 목표·달성 기록에서 목표를 설정하고 선물을 확인합니다. 한 입력으로 여러 목표를 달성하면 한 축하창에 표시됩니다.
    4. 점수판 설정 → 추격자에서 학급·모둠 기준과 패널티 문구를 각각 정합니다. 기준 미만인 대상은 빨갛게 표시됩니다. 추격 바를 누르면 편집할 수 있습니다.

    기기 연결·동기화

    1. 더 보기 → 기기 연결에서 다른 기기를 연결합니다. 이미지·PDF 원본은 필요할 때 파일 관리에서 받습니다.
    2. 화면 동기화 오른쪽 ▴에서 탭을 선택하고 본문을 누르면 페이지와 확대 위치가 공유됩니다. 창 안의 전체선택·전체해제는 대상 목록에만 적용됩니다.
    3. 같은 기기에서 효과음을 낼 탭은 탭 선택 창의 스피커 버튼으로 지정합니다. 가리개 열림 상태는 가리개 왼쪽 체크로 페이지별로 공유합니다.
    4. 같은 브라우저의 탭은 칠판 내용을 공유합니다. 연결 기기에서 같은 점수 항목에 직접 입력이 겹치면 점수판의 점수 충돌 확인에서 값을 비교할 수 있습니다.
    충돌 처리

    전자칠판

    • 서로 다른 페이지와 개체를 수정하면 두 변경이 모두 반영됩니다.
    • 같은 개체는 서버에 마지막으로 도착한 완료 편집을 적용합니다. 입력 중인 텍스트는 편집을 완료할 때 보냅니다.
    • 같은 개체의 삭제와 편집은 서버 도착 순서를 따릅니다. 페이지가 삭제되면 그 페이지의 뒤늦은 편집은 적용하지 않습니다.
    • 전자칠판 실행 취소는 해당 페이지의 최근 공유 작업을 취소합니다. 텍스트 입력 중 Ctrl+Z는 입력을 되돌립니다.

    점수판

    • 각 기기의 점수 증감은 한 번씩 합산합니다. 삭제된 모둠의 점수 조작은 적용하지 않습니다.
    • 같은 학급 또는 모둠 점수에 직접 입력이나 초기화가 겹치면 점수 항목별로 비교합니다. 서버 값과 각 기기의 마지막 입력값을 표시하고, 같은 값은 묶습니다.
    • 선택한 값은 그 항목에만 적용됩니다. 비교 중 변경이 들어오면 최신 값을 다시 확인할 수 있습니다.

    기기 연결

    처음 연결하기

    Firebase 설정을 단계별로 진행하고 이 기기의 칠판을 공유합니다.

    이 기기 추가하기

    이미 공유 중인 칠판의 QR 또는 연결 키를 사용합니다.

    1. 먼저 연결한 기기의 기기 연결에서 연결 링크를 복사합니다. 링크를 열었다면 아래에 자동으로 입력됩니다.
    2. 기기 이름을 입력하고 연결 코드를 발급합니다.
    3. 먼저 연결한 기기에 연결 코드를 입력하고 승인합니다. 이 기기의 이전 칠판은 로컬에 보관됩니다.

    기존 칠판의 QR을 스캔하거나 연결 키를 붙여넣으세요. 이 기기의 이전 칠판은 로컬에 보관됩니다.
