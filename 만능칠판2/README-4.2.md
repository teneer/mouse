# 만능칠판 4.2 (4.1 원본 기준 재작업)

서버: `python -m http.server 8000`, localhost:8000/wb4review/ 접속. 직접 HTML 파일을 열면 저장소 및 ES 모듈이 동작하지 않습니다. 기존 4.1 데이터와 같은 출처의 IndexedDB를 사용하므로 먼저 JSON 백업을 권장합니다.

## 정한 UX 기본값
- 레이저: 화면 위 빨간 점과 경로, 약 0.9초 뒤 사라지며 저장·실행 취소 대상이 아닙니다.
- 지우개: 화면상 24px 사각형에 걸친 객체를 통째로 삭제합니다(그룹은 한 객체). 한 제스처를 한 번의 실행 취소로 기록합니다.
- 단계별 크기(px): 펜 [1,3,5,9,14], 형광펜 [10,18,30,42,56], 글자 [20,32,48,64,96], 초기 단계 3.
- 빠른 색상 해제 시 현재 색상은 유지되며 하단의 현재색 표시 대신 더보기의 색상 입력에 계속 표시합니다. 색상 슬롯 설정은 브라우저 로컬 스토리지에 저장합니다.
- 그룹 내부 진입: 그룹을 더블클릭하면 내부 객체 선택(텍스트는 편집)을 시작합니다. 편집 후 그룹을 다시 구성합니다.
- 새 텍스트박스 배경은 투명하고 외곽선은 없음입니다. 객체 속성은 현재 빠른 색상·크기와 별도로 저장됩니다.

## 브라우저 실기기 확인이 필요한 항목
그룹 내부 객체 이동 후 그룹 재결합 및 실행 취소, 하위 객체의 멀티선택, 긴 터치와 캔버스 드래그 충돌, 실제 PDF/이미지 저장·복구, 텍스트 편집 중 포커스 이동, 툴바가 좁은 화면에 맞는지 반드시 검증하세요. 자동 테스트는 브라우저 내 Fabric 동작까지 보증하지 않습니다.
