## 확정 요구와 구현

- `main`의 `클래스레볼루션/`만 변경한다. 다른 만능칠판 폴더는 변경하지 않는다.
- 전자칠판은 현재 메뉴와 iframe 로딩에서 제외한다. 복사된 소스는 보존한다.
- 목록보기: 크림색 바탕, 흰 카드, 왼쪽 정지 캐릭터, 오른쪽 파란 점수와 번호/이름, 노란 선택, 하단 황금알/별길.
- 자리배치: 갈색 모둠 테두리, 회색 학생 자리, 모둠 이름/합계. 교실 전체를 180도 전환하되 글자는 정방향. 학생·모둠은 드래그 또는 원본/목적지 순서 선택으로 이동·교환. 모둠 이름으로 구성원 일괄 선택.
- 점수 입력: 상점은 파랑, 감점은 분홍 사유 화면. 한 번에 한 사유·한 변동량을 모든 선택 학생에게 동일 적용. 상점/감점별 최근 사유 10개·즐겨찾기 10개.
- 상세연출: 개인/학급점수판에서 대상 학생 전원과 점수 변동량·사유. 상점은 2프레임 움직임, 감점은 정지 이미지와 짧은 플래시. 메달/날개/배경은 제공 스프라이트 사용.
- 하단 팝업: 명렬에서는 현재 작업을 덮지 않는 하단 표시. 사유·변동량·대상 이름을 모두 표시. 다른 탭에서도 수신한 탭의 현재 모드에 따른 형식 사용.
- 학급점수: 하늘·별길·황금알·오른쪽 나무. 원본에 없는 마을 배경 제거. 평상시 캐릭터 정지, 상점 도착 때만 움직임. 학급 이름과 목표/보상 최대 10개 저장.
- 명렬: 체크, ◎○△×, 5~1, Score. 날짜별 기록·열별 통계·항목 수정/순서변경/보관/복원. 기록값/체크 여부로 학생 선택 후 개인점수를 별도로 수동 지급한다. 기록과 해제 자체로 개인점수를 지급/회수하지 않는다. 이전 `rewardPoints`는 자동 지급에 사용하지 않는다.
- 개인점수 차감에 따른 별길 후퇴와 황금알 경계 복원은 기존 `growth-path.js` 엔진을 유지한다. 별길만 따로 차감하는 입력은 없다.

## 실제 브라우저 검증

Chrome, localhost, 1363×936, 가상 학생 24명/모둠 6개. 실제 UI 입력으로 검증했다.

| 항목 | 관찰 결과 |
|---|---|
| 명단과 목록 | 24명 붙여넣기 등록, 정지 아바타·점수·이름 표시 |
| 동일한 일괄 점수 | 두 학생에게 각 +6 → 각 6점, 황금알 1/별길 2 |
| 감점과 황금알 경계 | 같은 두 학생 각 −2 → 각 4점, 황금알 0/별길 8 |
| 상세연출 | 복수 학생 이름·사유·각 변동량 표시. 상점 DOM은 avatar-fx, 감점 DOM은 avatar-still. 상점 메달/배경의 실제 표시 확인 |
| 체크와 수동 지급 | 두 학생 체크 후 개인점수 4/5 유지. 체크 대상 선택 후 각 +3 수동 지급 → 7/8. 하단 팝업에 두 이름·사유·각 +3 표시 |

## 완료 범위의 한계와 다음 과제

원본 사이트의 모든 기능을 완성했다는 의미는 아니다. 영상의 미요청 룰렛·사다리·타이머·과제 관리는 추가하지 않았다.

- 학생 휴지통/복원, 점수 되돌리기·관리자 직접 조정은 아직 후속 과제다.
- 학급 목표/보상은 설정·표시까지이며 목표 달성 전용 연출과 원본의 나무 단계 전체는 미완성이다.
- 감점 상세연출 전체의 프레임별 시각 일치, 삼성브라우저/실물 전자칠판·모바일 터치 환경 검증은 남아 있다.
- 이번 수정에서는 데이터 스키마와 점수 엔진을 바꾸지 않았다. 백업/복원의 이전 검증을 재실행한 것으로 보고하지 않는다.
- 참고 화면에서 결정할 수 없는 동작·정책은 사용자가 결정한다. 추정 구현으로 확정하지 않는다.
