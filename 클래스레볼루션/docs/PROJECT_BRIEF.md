# 프로젝트 개요 및 사용자 요구

## 1. 목적

`클래스레볼루션`은 교실에서 사용하는 여러 도구를 한 앱으로 묶는 학급 운영 플랫폼이다. 교사는 하나의 화면에서 전자칠판, 학생 개인 점수, 모둠 점수, 학급 성장 점수, 체크리스트를 사용한다.

## 2. 현재 개발 범위

| 모듈 | 현재 범위 | 비고 |
|---|---|---|
| 전자칠판 | 현재 제외 | 독립 복사본 보존, 메뉴와 iframe 로딩 제외 |
| 점수판 | 포함 | 개인·모둠·학급 점수 통합 |
| 학급 성장 | 포함 | 점수 기여가 모여 학급 점수로 이어지는 시각화 |
| 체크리스트 | 포함 | 학생별 활동·수행 기록 |
| 과제 관리 | 후속 단계 | 지금은 개발하지 않음 |

## 3. 사용자가 명시한 제품 요구

### 화면과 탐색
- 영상처럼 상단/사이드 메뉴에서 모드를 선택해 전체 화면으로 전환한다.
- 전자칠판과 점수판을 동시에 띄우는 분할 화면은 사용하지 않는다.
- 모드가 바뀌어도 공통 데이터와 공통 피드백 시스템을 사용한다.
- 다른 탭에서 점수가 변경되면 현재 탭이 어느 모드에 있더라도 팝업으로 알려준다.

### 저장과 동기화
- 우선 로컬 DB로 작동한다.
- 같은 PC에서 동일 앱을 여러 브라우저 탭으로 열었을 때 데이터 변경을 실시간 전달한다.
- JSON 백업 및 복원을 제공한다.
- 클라우드/서버 저장은 로컬 버전이 안정된 뒤 별도 결정한다. 현재 단계에서 Firebase를 필수 전제로 만들지 않는다.

### 주요 기능
- 학생 개인 점수, 모둠 점수, 학급 점수를 하나의 데이터 체계로 관리한다.
- 체크리스트를 포함한다.
- 전자칠판은 기존 만능칠판 6.0의 기능을 활용하되 클래스레볼루션에 독립된 코드로 둔다.

### 디자인과 참고 자료
- 제공된 영상은 기존 앱의 사용 흐름·기능·애니메이션을 이해하는 참고 자료다.
- 원본 클래스123 영상·스크린샷의 디자인과 동작을 충실히 구현한다. 사용자가 요청하지 않은 영상 속 기능은 제외한다.
- 사용자가 제공한 아바타, 배경, 스프라이트, 효과, 사운드 에셋을 활용한다.

## 4. 범위에 포함하지 않는 것

- 과제 생성·배포·제출·평가·갤러리 등 과제 관리 전반은 후속 단계다.
- 영상에 보이는 룰렛·사다리타기·랜덤 추첨 등은 별도 확인 없이 필수 범위로 확정하지 않는다.
- 기존 레거시 대시보드의 모든 기능을 무조건 이식하지 않는다. 수업에서 필요한지 검토한 후 결정한다.

## 5. 이후 확정된 정책

개인 감점 시 별길 후퇴·황금알 감소, 명렬 기록과 개인점수 분리/수동 지급, 한 번에 동일 점수, 모드별 상세/하단 피드백, 자리 180도 전환과 학생/모둠 이동은 확정되었다. 구체적인 현재 사양은 [원본 화면 복원 기록](REFERENCE_RESTORATION.md)을 따른다.

## 6. 초기 미결 목록 — 이후 결정은 위 절 우선

다음은 현재 코드에 일부 가정이 들어가 있지만 사용자 확정 사양으로 보면 안 된다.

1. 개인 점수와 학급 점수의 정확한 환산 비율 및 환산 시점
2. 개인 감점이 이미 적립된 학급 성장 기여를 취소하는지
3. 학급 점수의 교사 직접 가감·초기화·되돌리기 방식
4. 모둠 점수 산정이 개인 점수 합계인지, 별도 모둠 점수인지
5. 체크리스트의 종류·반복 주기·완료 조건·보상 방식·학생 권한
6. 학생·모둠 관리의 세부 UX(휴지통, 복원, 그룹 이동, 정렬 등)
7. 랜덤 추첨·룰렛·사다리타기 기능의 실제 포함 여부

정책이 미확정이면 Work는 먼저 기존 영상·레거시 코드·현재 구현을 대조하고, 사용자 결정이 필요한 항목은 임의로 확정하지 않는다.
