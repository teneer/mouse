화면 저장

현재 페이지를 별도의 저장 화면으로 보관합니다.

미리보기는 저장할 때의 현재 위치와 현재 배율을 기준으로 합니다.

저장된 화면 불러오기

저장 당시 위치 · 배율 기준 미리보기입니다. 화면을 불러오면 새 페이지가 추가됩니다.

저장된 화면이 없습니다.

    만능칠판 사용 안내

    • 하단 툴바의 현재 색상과 크기를 누르면 선택 목록이 열립니다. 선택 모드의 우클릭 메뉴와 개체를 길게 눌러 여는 메뉴에서도 바로 바꿀 수 있습니다. 색상·크기 1~5단계는 펜·형광펜·텍스트가 공유합니다. 그룹 안의 객체는 그룹 더블클릭으로 내부 편집을 시작합니다.
    • 선택/이동 버튼을 누르면 모드가 바뀝니다. 이동 모드에서 화면을 끌거나, Space를 누른 채 끌거나, 마우스 가운데 버튼으로 이동할 수 있습니다.
    • 마우스 휠 또는 −/＋로 10%~1,000%까지 확대·축소합니다. 홈은 100% 기본 위치로 돌아갑니다.
    • 선택 모드에서 드래그하거나 Shift+클릭으로 여러 객체를 선택합니다. Ctrl/Cmd+G로 그룹, Ctrl/Cmd+Shift+G로 언그룹합니다.
    • Ctrl/Cmd+C·X·V로 시스템 클립보드를 사용합니다. 복사 버튼은 선택 객체를 PNG와 편집 가능한 데이터로 복사합니다. 외부 앱이 데이터를 제거하면 이미지나 텍스트로 붙여넣습니다. 권한이 거부되면 키보드 단축키를 사용해주세요.
    • PNG/JPG/GIF/PDF를 칠판에 끌어 넣거나 더 보기 → 이미지·PDF를 사용합니다. GIF는 정지 프레임이고, PDF는 칠판에서 필요한 쪽을 표시합니다. PDF 문자 편집은 지원하지 않습니다.
    • 각 페이지의 편집 내용은 자동저장됩니다. 언두/리두는 페이지별로 최대 40개이며 용량에 따라 더 줄어듭니다. 새로고침과 원격 변경 수신 시 해당 기록은 초기화됩니다. 페이지 삭제와 저장 화면 삭제는 되돌릴 수 없습니다.
    • 더 보기 → 기기 연결로 다른 기기에서 같은 칠판을 사용합니다. 파일은 더 보기 → 파일 관리에서 필요한 기기로 받습니다.
    • 기기 연결을 사용하지 않을 때 같은 브라우저 프로필에서 칠판 내용을 공유합니다. 한 탭에서 화면 동기화를 켜면 모든 탭이 페이지·확대·화면 위치·점수판 상태를 공유합니다. 같은 페이지를 동시에 수정하면 충돌 복구 페이지를 추가합니다.
    • 자동저장은 브라우저 저장소이지 서버 백업이 아닙니다. 더 보기 → JSON 백업으로 정기 보관해주세요. 주소/브라우저/프로필이 바뀌면 JSON 백업을 직접 가져와야 합니다.
    • 이전 데이터 버튼은 같은 출처의 구버전 저장 화면과 자동저장 내용만 가져옵니다. 기존 객체는 모두 일반 객체가 됩니다. 원본 DB는 수정하지 않습니다.
    충돌 처리

    전자칠판

    • 서로 다른 페이지와 개체를 수정하면 두 변경이 모두 반영됩니다.
    • 같은 개체는 서버에 마지막으로 도착한 완료 편집을 적용합니다. 입력 중인 텍스트는 편집을 완료할 때 보냅니다.
    • 같은 개체의 삭제와 편집은 서버 도착 순서를 따릅니다. 페이지가 삭제되면 그 페이지의 뒤늦은 편집은 적용하지 않습니다.
    • 전자칠판 실행 취소는 해당 페이지의 최근 공유 작업을 취소합니다. 텍스트 입력 중 Ctrl+Z는 입력을 되돌립니다.

    점수판

    • 각 기기의 점수 증감은 한 번씩 합산합니다. 삭제된 모둠의 점수 조작은 적용하지 않습니다.
    • 같은 학급 또는 모둠 점수에 직접 입력이나 초기화가 겹치면 점수 항목별로 비교합니다. 서버 값과 각 기기의 마지막 입력값을 표시하고, 같은 값은 묶습니다.
    • 선택한 값은 그 항목에만 적용됩니다. 비교 중 변경이 들어오면 최신 값을 다시 확인할 수 있습니다.

    기기 연결

    처음 연결하기

    Firebase 설정을 단계별로 진행하고 이 기기의 칠판을 공유합니다.

    이 기기 추가하기

    이미 공유 중인 칠판의 QR 또는 연결 키를 사용합니다.

    1. 먼저 연결한 기기의 기기 연결에서 연결 링크를 복사합니다. 링크를 열었다면 아래에 자동으로 입력됩니다.
    2. 기기 이름을 입력하고 연결 코드를 발급합니다.
    3. 먼저 연결한 기기에 연결 코드를 입력하고 승인합니다. 이 기기의 이전 칠판은 로컬에 보관됩니다.

    기존 칠판의 QR을 스캔하거나 연결 키를 붙여넣으세요. 이 기기의 이전 칠판은 로컬에 보관됩니다.

    연결된 기기

      현재 칠판과 점수를 이 기기에 저장한 뒤 로컬에서 이어서 사용합니다. 다른 기기는 계속 공유 칠판을 사용합니다.

      기기 추가

      새 기기로 QR을 스캔하거나 ‘연결 키 복사’를 눌러 새 기기에 붙여넣으세요.
