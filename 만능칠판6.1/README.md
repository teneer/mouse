# 만능칠판 6.1 — 개선 작업판

## 구조
- 메인 문서와 브라우저 탭은 만능칠판 6.1으로 표시합니다.
- 점수판은 우측 뷰포트 고정 패널이며 확대/이동되는 Fabric 객체가 아닙니다.
- 툴바는 기존 위치 그대로 **브라우저 전체 너비**를 차지하며, 점수판의 아래 영역까지 공통으로 작동합니다.
- 상단 제목/상태 바는 추가하지 않았습니다. 원본의 자동저장 상태 토스트는 보존합니다.
- 점수판 HTML/JS/오디오 원본을 `score/`에 복사했고, 패널용 CSS와 크기 제어 JS를 추가했습니다. 원본 실행 경로에 런타임 의존하지 않습니다.

## 동작
- 툴바 `점수판`로 표시/숨김, 기본 분할 70:30.
- 경계선을 포인터로 이동하거나 방향키로 조절(2% / Shift+방향키 10%, Home/End = 20/90).
- 패널 열림·분할 비율은 `whiteboard.test.scorepanel.v1`, 점수판 표시 배율(60~150%)은 `whiteboard.test.score-scale.v1`에 보관.
- **자동 배치**는 상단 학급 점수와 하단 조작부를 제외한 실제 카드 영역에서 1~6열을 비교합니다. 모든 카드를 가장 크게 맞추고, 가독성을 확보하려면 목록에 스크롤을 제공합니다.
- **열 수 고정**은 1~6 사이의 정수를 직접 입력합니다. 모둠 수가 지정한 열보다 적으면 실제 모둠 수만큼 중앙에 배치하고, 지정값은 저장합니다. 카드 영역이 좁거나 낮으면 필요한 방향으로 목록을 스크롤합니다. 배치 방식과 고정 열 수는 다음 접속에도 적용됩니다.

## 주의
- 이전과 동일한 IndexedDB/localStorage 키를 사용하므로 **같은 도메인의 원본과 데이터가 공유될 수 있습니다**. 수정 전에 JSON 백업을 권장합니다.
- Fabric.js 5.3.1 CDN 및 PDF.js 등의 원본 외부 의존성이 유지됩니다. 완전한 오프라인 실행은 지원하지 않습니다.
- 정적 호스팅(예: GitHub Pages)에서 `/만능칠판-test/index.html`로 진입해야 합니다. `file://` 직접 열기는 지원하지 않습니다.

## 테스트 현황
코드 통합·정적 구조 확인은 수행했습니다. 실제 브라우저에서 캔버스 필기/줌/텍스트/저장, 좁은 패널의 점수·목표·모둠·설정, 음향·애니메이션, 동시 탭 동기화 및 제스처를 추가로 검증해야 합니다. 원본 기능 검증을 통과하기 전에는 완성 판정하지 않습니다.


## 2026-11 UI 개정
- 캔버스는 점수판 ON/OFF와 무관하게 원래 전체 뷰포트 크기로 유지합니다. 패널은 오른쪽 위에 겹쳐 표시합니다.
- 기존 캔버스의 확대 비율/이동 행렬을 패널 토글·경계 조절 시 변경하지 않습니다.
- 툴바는 한 줄, 그룹 내부 5px / 그룹 사이 10px 간격, 좁으면 가로로 끌어 이동합니다.
- 점수판은 하단까지 이어지고, 콘텐츠에는 툴바 가림 방지 여백을 둡니다.
- 톱니바퀴에서 모둠 카드 비율(16:9 또는 4:3)과 점수 표시 배율을 설정합니다. 표시 배율과 카드 비율은 다시 접속해도 유지됩니다.
- 학급 점수와 연동 진행막대는 상단에 표시합니다. 학급 점수 영역은 패널의 너비를 사용하며 제목, 조작부, 연동 안내의 높이에 맞춥니다. 모둠 카드 그리드 전체를 가운데에 배치하고, 마지막 줄은 첫 번째 열부터 채웁니다. 카드 크기에는 상한을 두어 큰 화면에서도 학급 점수가 중심이 되도록 합니다. 일괄 조작은 모둠 목록을 스크롤해도 유지되고, 한 줄에 들어가지 않을 때는 위에 전체선택·되돌리기, 아래에 점수 입력·반영을 배치합니다. 점수판 빈 배경을 누르면 선택이 해제됩니다. 모둠 카드의 × 또는 점수판 관리에서 모둠을 삭제할 수 있습니다.

## 여러 기기에서 같은 칠판 사용하기

**더 보기 → 기기 연결 → 처음 연결하기**에서 Firebase 설정 안내를 엽니다.
Spark 프로젝트에 웹 앱과 Firestore Standard 기본 데이터베이스를 만들고,
Authentication의 익명 로그인을 활성화합니다. Firestore 규칙 탭에
[firestore.rules](firestore.rules)를 적용한 뒤 웹 앱 설정값을 붙여넣습니다.
첫 동기화는 이 기기의 칠판 페이지와 학급·모둠 점수로 시작합니다.
이미 연결된 공유 칠판은 교실 PC의 **더 보기 → 기기 연결 → 이 기기 점수로 공유 시작**에서 시작 점수를 한 번 지정합니다.
저장 화면은 브라우저에 보관합니다.

등록된 기기에서 **더 보기 → 기기 연결 → 기기 추가**를 열고 초대를 만듭니다.
새 기기로 QR을 스캔하거나 **이 기기 추가하기**에서 복사한 연결 키를 붙여넣습니다.
QR과 연결 키는 **초대 종료**를 누를 때까지 여러 기기에 재사용할 수 있습니다.
초대 종료는 이후 등록만 막습니다. 이미 등록한 기기를 끊으려면 **연결된 기기** 목록에서 해당 기기를 해제합니다.
키로 등록한 기기는 편집하고 관리할 수 있으므로 본인 기기에만 전달합니다.
연결을 끊은 기기에 키가 남아 있다면 **초대 종료**도 눌러 해당 키로 재등록할 수 없게 합니다.
기존 연결 코드 승인 방식은 **다른 연결 방법**에서 이용할 수 있습니다.
이미 설정한 Firebase 프로젝트에서도 QR·키 연결과 기기 해제를 사용하려면
최신 [firestore.rules](firestore.rules)를 게시해야 합니다.
로컬 칠판으로 돌아가면 미전송 작업을 포함해 현재 칠판과 점수를 이 기기에서 이어 씁니다.
연결이 끊겨도 공유 칠판은 화면에 유지되고 툴바에 전송 대기 건수가 표시됩니다.
재연결하면 점수 증감을 조작별로 한 번씩 반영합니다. 초기화나 직접 입력이 다른 점수 변경과 겹치면
점수판의 **점수 충돌 확인**에서 현재 공유 점수와 변경 결과를 비교해 하나를 적용합니다.
**화면 동기화**를 켠 기기끼리 페이지, 확대 배율, 화면 중심을 공유합니다.

펜선과 개체 편집은 서버가 받은 완료 순서대로 적용합니다. 텍스트 입력 중에는
해당 개체의 초안을 브라우저에 유지합니다. 다른 기기에서 페이지를 삭제하면
그 페이지의 편집도 취소됩니다. 일반 개체 변경은 칠판의 실행 취소와 다시 실행에서
기기 간에 공유하며, 페이지 삭제는 되돌릴 수 없습니다.

이미지와 PDF 원본은 기기에 보관합니다. **더 보기 → 파일 관리**에서 파일의
크기와 위치를 확인하고, 다른 기기에 있는 파일만 선택하여 받습니다.
보낼 기기에서 앱을 열어 둬야 하며, 네트워크가 직접 연결을 차단한 경우 점선 상자가
유지됩니다. Cloud Storage와 TURN 중계는 사용하지 않습니다.
PDF 가져오기의 파일 크기·쪽 수 상한은 제거했습니다. 브라우저 저장 공간과
PDF를 여는 데 필요한 메모리는 기기에 따라 다릅니다.

## 칠판 도구와 점수판 조작

칠판 툴바는 한 줄에 들어갈 때 가운데에 배치됩니다. 화면이 좁을 때는 툴바를
가로로 끌어 숨은 도구를 볼 수 있습니다. 페이지 번호를 누르면 썸네일 목록이
열립니다. 썸네일을 눌러 이동하고, 길게 눌러 순서를 바꾸며, 끝의 +로 추가합니다. 썸네일의 … 메뉴에서 페이지 이름 편집, 복제, 삭제를 합니다.

색상·크기 세부속성에서 기본값을 확인하고 즐겨찾기 색상과 크기 세트를 각각 하나씩
등록할 수 있습니다. 배경 버튼 또는 빈 칠판 우클릭에서 색과 무늬를 바꿉니다.
이미지·PDF를 겹쳐 배치하거나 배경에 고정할 수 있고, 고정개체 관리에서 여러 개체의
고정을 해제할 수 있습니다.

Firebase 연결 없이도 같은 브라우저 프로필의 탭에서 화면 동기화를 사용할 수
있습니다. 한 곳에서 화면 동기화를 켜면 해당 브라우저의 페이지, 확대, 화면 중심, 점수판 열림 상태와 분할 비율·표시 배율이 전체 탭 또는 연결 기기에 적용됩니다.

학급 점수는 표시 배율에 따른 기본 글자 크기를 유지하고, 숫자와 조작 버튼에
필요한 가로 공간이 부족할 때 줄어듭니다. 모둠 점수의 글자 크기는 각 카드의
크기에 맞춰 조절됩니다.

모둠 점수와 환산 점수는 즉시 저장합니다. 금색 막대가 가득 차면 각 칸의 별이 학급 점수로 이동합니다. 같은 방향의 연속 환산은 별을 한 번 이동시키고 학급 점수에 합계를 표시합니다.

색상·크기 세부속성 창의 저장 버튼으로 즐겨찾기 색상과 크기를 함께 적용합니다. 고정개체 관리에서는 개체 종류와 썸네일을 보고 고정을 해제할 수 있습니다. 더 보기의 텍스트 박스 기본속성은 새 개체에 적용되고, 개체 우클릭의 텍스트박스 속성은 해당 개체의 배경과 사각 테두리를 바꿉니다.


## 6.1 개선 반영
- 화면 전송은 버튼을 눌러 대상 탭을 선택한 뒤 현재 화면 상태를 한 번 전송합니다. 선택 상태는 지속 동기화 구독이 아닙니다.
- 점수판 원격 미리보기 이벤트는 영구 저장 대기열과 분리해 먼저 전송하고, 확정 상태 수신 때 미리보기 중복 재생을 막습니다.
- 일반 음량(100% 이하)은 AudioContext 경유 없이 HTMLAudioElement로 재생하며 원본 음원은 미리 불러옵니다. 100% 초과는 Web Audio 경로를 사용합니다.
- 누락된 이미지/PDF 객체도 선택·이동·삭제할 수 있도록 상호작용 잠금을 해제했습니다. 실제 픽셀 내용은 파일이 없으면 복구되지 않으며 자리표시자로 표시됩니다.
- 객체 이름은 우클릭 메뉴에서 변경하고, 다중 선택 시 입력 이름에 (1), (2)…를 붙입니다. 파일 관리에는 개체 종류·이름과 페이지 위치를 표시합니다.
- 툴바 점수판 버튼은 고정 명칭 '점수판'이며 활성 상태만 강조합니다.
