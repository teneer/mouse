# 만능칠판-test — 통합 테스트 (전자칠판 4.2 기반)

## 구조
- 메인 문서 자체가 만능칠판 4.2(원본의 버전 상수 `4.2.0`, HTML 리소스 표기 `4.2.1`)입니다.
- 점수판은 우측 뷰포트 고정 패널이며 확대/이동되는 Fabric 객체가 아닙니다.
- 툴바는 기존 위치 그대로 **브라우저 전체 너비**를 차지하며, 점수판의 아래 영역까지 공통으로 작동합니다.
- 상단 제목/상태 바는 추가하지 않았습니다. 원본의 자동저장 상태 토스트는 보존합니다.
- 점수판 HTML/JS/오디오 원본을 `score/`에 복사했고, 패널용 CSS와 크기 제어 JS를 추가했습니다. 원본 실행 경로에 런타임 의존하지 않습니다.

## 동작
- 툴바 `📊 점수판 열기`로 표시/숨김, 기본 분할 70:30.
- 경계선을 포인터로 이동하거나 방향키로 조절(2% / Shift+방향키 10%, Home/End = 20/90).
- 패널 열림·분할 비율은 `whiteboard.test.scorepanel.v1`, 점수판 표시 배율(60~150%)은 `whiteboard.test.score-scale.v1`에 보관.
- **자동 배치**는 상단 학급 점수와 하단 조작부를 제외한 실제 카드 영역에서 1~6열을 비교합니다. 모든 카드를 가장 크게 맞추고, 가독성을 확보하려면 목록에 스크롤을 제공합니다.
- **열 수 고정**은 1~6 사이의 정수를 직접 입력합니다. 모둠 수가 지정한 열보다 적으면 실제 모둠 수만큼 중앙에 배치하고, 지정값은 저장합니다. 카드 영역이 좁거나 낮으면 필요한 방향으로 목록을 스크롤합니다. 배치 방식과 고정 열 수는 다음 접속에도 적용됩니다.

## 주의
- 이전과 동일한 IndexedDB/localStorage 키를 사용하므로 **같은 도메인의 원본과 데이터가 공유될 수 있습니다**. 수정 전에 JSON 백업을 권장합니다.
- Fabric.js 5.3.1 CDN 및 PDF.js 등의 원본 외부 의존성이 유지됩니다. 완전한 오프라인 실행은 지원하지 않습니다.
- 정적 호스팅(예: GitHub Pages)에서 `/만능칠판-test/index.html`로 진입해야 합니다. `file://` 직접 열기는 지원하지 않습니다.

## 테스트 현황
코드 통합·정적 구조 확인은 수행했습니다. 실제 브라우저에서 캔버스 필기/줌/텍스트/저장, 좁은 패널의 점수·목표·모둠·설정, 음향·애니메이션, 동시 탭 동기화 및 제스처를 추가로 검증해야 합니다. 원본 기능 검증을 통과하기 전에는 완성 판정하지 않습니다.


## 2026-11 UI 개정
- 캔버스는 점수판 ON/OFF와 무관하게 원래 전체 뷰포트 크기로 유지합니다. 패널은 오른쪽 위에 겹쳐 표시합니다.
- 기존 캔버스의 확대 비율/이동 행렬을 패널 토글·경계 조절 시 변경하지 않습니다.
- 툴바는 한 줄, 그룹 내부 5px / 그룹 사이 10px 간격, 좁으면 가로 스크롤합니다.
- 점수판은 하단까지 이어지고, 콘텐츠에는 툴바 가림 방지 여백을 둡니다.
- 톱니바퀴에서 모둠 카드 비율(16:9 또는 4:3)과 점수 표시 배율을 설정합니다. 표시 배율과 카드 비율은 다시 접속해도 유지됩니다.
- 학급 점수와 연동 진행막대를 점수판 너비의 상단 요약 영역에 표시합니다. 모둠 카드 그리드 전체를 가운데에 배치하고, 마지막 줄은 첫 번째 열부터 채웁니다. 카드 크기에는 상한을 두어 큰 화면에서도 학급 점수가 중심이 되도록 합니다. 일괄 조작은 모둠 목록을 스크롤해도 유지되고, 좌우 버튼 그룹이 한 줄에 들어가지 않을 때만 줄을 바꿉니다. 점수판 빈 배경을 누르면 선택이 해제됩니다. 모둠 삭제는 점수판 관리에서 합니다.

## 여러 기기에서 같은 칠판 사용하기

**더 보기 → 기기 연결 → 처음 연결하기**에서 Firebase 설정 안내를 엽니다.
Spark 프로젝트에 웹 앱과 Firestore Standard 기본 데이터베이스를 만들고,
Authentication의 익명 로그인을 활성화합니다. Firestore 규칙 탭에
[firestore.rules](firestore.rules)를 적용한 뒤 웹 앱 설정값을 붙여넣습니다.
첫 동기화는 현재 기기의 칠판 페이지로 시작합니다. 저장 화면과 점수판은
각 브라우저에서 관리합니다.

다른 기기에서는 먼저 연결한 기기의 링크를 열고 연결 코드를 발급합니다.
이미 연결된 기기에서 코드를 승인하면 공용 칠판이 열립니다.
로컬 칠판으로 돌아가면 이전 로컬 자료를 계속 사용할 수 있습니다.
**화면 동기화**를 켠 기기끼리 페이지, 확대 배율, 화면 중심을 공유합니다.

펜선과 개체 편집은 서버가 받은 완료 순서대로 적용합니다. 텍스트 입력 중에는
해당 개체의 초안을 브라우저에 유지합니다. 다른 기기에서 페이지를 삭제하면
그 페이지의 편집도 취소됩니다. 일반 개체 변경은 칠판의 실행 취소와 다시 실행에서
기기 간에 공유하며, 페이지 삭제는 되돌릴 수 없습니다.

이미지와 PDF 원본은 기기에 보관합니다. **더 보기 → 파일 관리**에서 파일의
크기와 위치를 확인하고, 다른 기기에 있는 파일만 선택하여 받습니다.
보낼 기기에서 앱을 열어 둬야 하며, 네트워크가 직접 연결을 차단한 경우 점선 상자가
유지됩니다. Cloud Storage와 TURN 중계는 사용하지 않습니다.
PDF 가져오기의 파일 크기·쪽 수 상한은 제거했습니다. 브라우저 저장 공간과
PDF를 여는 데 필요한 메모리는 기기에 따라 다릅니다.
