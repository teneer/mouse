# 클래스레볼루션 (Class Revolution)

통합 학급 운영 플랫폼의 초기 구현 및 Work 인수인계 문서입니다.

## 시작점
- 작업 브랜치: `main`
- 프로젝트 경로: `클래스레볼루션/`
- [Work 인수인계 문서](WORK_HANDOFF.md)
- [세부 문서 목록](docs/README.md)
- [Work 시작 지시문](docs/WORK_START_PROMPT.md)

## 제품 범위
전자칠판 · 개인/모둠/학급 점수 통합관리 · 체크리스트. 과제 관리는 후속 단계입니다. 화면은 분할이 아니라 전체 화면 모드 전환 방식입니다.

## 기술 기준
- IndexedDB 로컬 우선
- BroadcastChannel + storage event로 동일 PC 다중 탭 알림
- JSON 전체 백업/복원
- 전자칠판은 `만능칠판-test/` 6.0.0 복사본을 사용하며 원본 폴더는 수정하지 않음

## 현재 상태
초기 기능 골격과 문서화가 완료된 상태입니다. 성장 화면용 이미지와 아바타를 앱 경로에 배치했습니다. 브라우저 검증 현황은 [QA 체크리스트](docs/QA_CHECKLIST.md)를 참고하세요. 문서의 구현 현황과 개발 과제를 확인하고 작업하세요.
