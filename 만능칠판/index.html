    만능칠판 사용 안내

    • 선택/이동 버튼을 누르면 모드가 바뀝니다. 이동 모드에서 화면을 끌거나, Space를 누른 채 끌거나, 마우스 가운데 버튼으로 이동할 수 있습니다.
    • 마우스 휠 또는 −/＋로 10%~1,000%까지 확대·축소합니다. 홈은 100% 기본 위치로 돌아갑니다.
    • 선택 모드에서 드래그하거나 Shift+클릭으로 여러 객체를 선택합니다. Ctrl/Cmd+G로 그룹, Ctrl/Cmd+Shift+G로 언그룹합니다.
    • Ctrl/Cmd+C·X·V로 시스템 클립보드를 사용합니다. 복사 버튼은 선택 객체를 PNG와 편집 가능한 데이터로 복사합니다. 외부 앱이 데이터를 제거하면 이미지나 텍스트로 붙여넣습니다. 권한이 거부되면 키보드 단축키를 사용해주세요.
    • PNG/JPG/GIF/PDF를 칠판에 끌어 넣거나 더 보기 → 이미지·PDF를 사용합니다. GIF는 정지 프레임이고, PDF는 쪽별 이미지로 세로 배치됩니다. PDF 문자 편집은 지원하지 않습니다.
    • 각 페이지의 편집 내용은 자동저장됩니다. 언두/리두는 페이지별로 최대 40개이며 용량에 따라 더 줄어듭니다. 새로고침과 원격 변경 수신 시 해당 기록은 초기화됩니다. 페이지 삭제와 저장 화면 삭제는 되돌릴 수 없습니다.
    • 같은 브라우저 프로필·같은 출처·같은 배포 폴더의 탭이 동기화됩니다. 현재 페이지 선택과 줌·이동은 탭별로 유지됩니다. 같은 페이지를 동시에 수정하면 충돌 복구 페이지를 추가합니다.
    • 자동저장은 브라우저 저장소이지 서버 백업이 아닙니다. 더 보기 → JSON 백업으로 정기 보관해주세요. 주소/브라우저/프로필이 바뀌면 JSON 백업을 직접 가져와야 합니다.
    • 이전 데이터 버튼은 같은 출처의 구버전 저장 화면과 자동저장 내용만 가져옵니다. 기존 객체는 모두 일반 객체가 됩니다. 원본 DB는 수정하지 않습니다.
