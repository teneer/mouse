# 화면 녹화 참고 가이드

세 영상은 기존 학급 운영 앱의 동작을 파악하기 위한 자료다. 아래 내용은 영상 전체를 프레임별로 완전 분석한 명세가 아니라, 업로드된 대표 프레임 시트와 접촉 시트에서 확인한 기능 구분이다. 세부 인터랙션을 구현하기 전에는 Work에서 원본 MP4를 직접 재생해 확인한다.

## 영상 1 — 별길·학급점수·모둠/개인 점수

- 원본: `screen_1743084583502.mp4`
- 길이: 111.466초
- 대표 프레임: `video1_sheet.jpg` (0~108초, 약 9초 간격)
- 상세 접촉 시트: `video1_contact.jpg`

화면에서 확인되는 흐름:
- 파란 하늘 배경 위에 별이 이어진 성장 경로
- 학생 아바타가 별길 위에 배치됨
- 황금 알/학급 점수 표시가 진행도에 따라 변화
- 점수 조정 모달과 점수 변경 확인
- 학급 성장 점수 전환 시 중앙 축하 연출
- 모둠별 점수 카드와 학생별 점수 화면
- 상점/벌점 구분 색상 및 학생별 피드백 화면

클래스레볼루션에 참고할 점:
- 성장 화면은 단순 숫자 표시가 아니라 학생 기여와 학급의 공동 성장을 시각화한다.
- 점수 변동은 화면에서 즉시 알아볼 수 있어야 한다.
- 학급 성장 연출과 일반 점수 입력 피드백은 구분할 필요가 있다.

## 영상 2 — 모둠 점수·랜덤 선택·게임형 도구

- 원본: `screen_1743085219666.mp4`
- 길이: 484.700초
- 대표 프레임: `video2_sheet.jpg` (0~480초, 약 40초 간격)
- 상세 접촉 시트: `video2_contact.jpg`

화면에서 확인되는 흐름:
- 모둠별 점수 카드와 카드 선택/강조
- 학생 선택 및 랜덤 선정 결과 표시
- 별도 도구 선택 화면
- 룰렛/돌림판을 통한 선택
- 사다리타기 화면과 결과 표시

클래스레볼루션에 참고할 점:
- 모둠 카드의 선택 상태와 점수 변화가 명확해야 한다.
- 랜덤 선정 도구는 점수판과 분리된 독립 도구 모드로 설계할 수 있다.
- 룰렛·사다리타기는 영상에 보인다는 이유만으로 이번 필수 범위에 포함하지 않는다. 별도 승인 후 개발한다.

## 영상 3 — 학생별 기록·체크 매트릭스·보고 화면

- 원본: `screen_1743085688672.mp4`
- 길이: 255.066초
- 대표 프레임: `video3_sheet.jpg` (0~252초, 약 21초 간격)
- 상세 접촉 시트: `video3_contact.jpg`

화면에서 확인되는 흐름:
- 학생 이름이 행으로 배치된 기록 매트릭스
- 여러 종류의 상태/기록 열과 색상으로 표시되는 셀
- 항목 설정 및 선택 관련 모달
- 학생별 목록·요약/통계 화면
- 별도 타이머 전체 화면
- 특정 학생을 중심으로 기록을 보는 화면

클래스레볼루션에 참고할 점:
- 체크리스트는 학생별 기록을 빠르게 입력하고 한눈에 비교할 수 있는 표 형태가 유용하다.
- 체크/상태별 색상은 일관된 의미를 가져야 한다.
- 상세 항목, 보상, 권한, 기간 집계 등은 사용자 요구를 확인한 뒤 구체화한다.

## 공통 제품 요구와 영상 해석의 경계

사용자가 확정한 요구:
- 메뉴/모드 전환형 전체 화면 UI
- 분할 화면 금지
- 다른 탭의 점수 변경도 공통 팝업으로 알림
- 로컬 DB, 같은 PC 탭 실시간 연동, JSON 백업/복원

영상에서 관찰한 후보 기능:
- 룰렛, 사다리타기, 랜덤 추첨
- 학생/모둠별 상세 화면
- 타이머
- 다양한 체크 매트릭스/리포트

후보 기능은 사용자 확인 없이 필수 개발 항목으로 승격하지 않는다.
