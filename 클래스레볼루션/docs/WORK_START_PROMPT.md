# ChatGPT Work 시작 지시문

> 2026-11-18 갱신: 현재 범위·구현·검증은 [원본 화면 복원 기록](REFERENCE_RESTORATION.md)을 우선한다. 전자칠판은 현재 제외, 명렬 자동 보상은 폐기, 원본 화면 복원이 기준이다. 아래 초기 계획/이력은 당시 기록이며 현 상태와 구분한다.


아래 지시문을 Work 작업 시작 메시지로 사용한다.

---

저장소 `https://github.com/teneer/mouse`의 `main` 브랜치에서 `클래스레볼루션/` 프로젝트를 이어서 개발하라.

먼저 다음 문서를 모두 읽어라.
1. `WORK_HANDOFF.md`
2. `docs/PROJECT_BRIEF.md`
3. `docs/IMPLEMENTATION_HISTORY.md`
4. `docs/ARCHITECTURE.md`
5. `docs/ASSET_CATALOG.md`
6. `docs/REFERENCE_VIDEO_GUIDE.md`
7. `docs/LEGACY_DASHBOARD_REFERENCE.md`
8. `docs/DEVELOPMENT_BACKLOG.md`
9. `docs/QA_CHECKLIST.md`

그다음 브랜치의 최신 HEAD와 실제 파일을 확인하고, 문서와 코드가 다른 부분이 있으면 문서를 그대로 믿지 말고 실제 코드를 기준으로 차이를 보고하라.

## 절대 제약
- `main` 브랜치에서 `클래스레볼루션/` 폴더 안의 변경만 커밋하고 푸시한다.
- `만능칠판-test/` 및 프로젝트 밖의 폴더는 수정하지 않는다.
- 전체 화면 모드 전환 구조를 유지한다. 분할 화면을 만들지 않는다.
- 과제 관리 모듈은 후속 단계이므로 지금 구현하지 않는다.
- 영상 속 룰렛·사다리타기 등은 사용자 확인 없이 필수 범위로 확대하지 않는다.
- 브라우저에서 실제 검증하지 않은 기능을 완료했다고 말하지 않는다.

## 첫 번째 수행 과제
1. `docs/ASSET_CATALOG.md`에 기록된 원본 첨부파일 목록을 확인한다. 성장 이미지 21개, 아바타 140개, MP3 9개를 저장소에 배치했다. ZIP·영상·레거시 소스 원본이 필요한 작업에서는 세션 첨부 자료를 확인한다. 파일을 찾은 척하거나 이름만으로 내용을 추정하지 않는다.
2. `assets/visuals/`와 `assets/avatars/`의 이미지가 화면에서 정상적으로 표시되는지 확인한다. ZIP 원본과 복원용 캡처는 별도 보존한다.
3. 현재 코드의 이미지 경로를 모두 조사해 404 없이 연결한다.
4. HTTPS/localhost에서 실행하고 원본 화면·모드 전환·탭 간 이벤트·백업/복원을 검증한다. 현재 전자칠판은 제외한다.
5. 레거시 수식과 현재 점수 엔진의 차이를 정리해, 감점과 학급 성장 환산 정책에서 사용자 결정이 필요한 부분을 분리 보고한다.

## 작업 방식
- 구현 전에 현재 코드와 원본 영상/에셋을 직접 확인한다.
- 큰 변경은 기능 단위로 나눠 커밋한다.
- 각 작업 후 수정 파일, 동작 변화, 테스트 결과, 미해결 사항을 보고한다.
- 기존 요구와 충돌하거나 사용자 결정이 필요한 정책은 임의로 결정하지 말고 질문한다.
- 작업 완료 보고에는 실제 테스트 환경과 재현 절차를 포함한다.
