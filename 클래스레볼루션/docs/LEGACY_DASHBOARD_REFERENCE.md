# 레거시 클래스 대시보드 소스 참고

## 1. 첨부 소스

- `index.html` — 17,714 bytes
- `app.js` — 44,907 bytes
- `style.css` — 56,995 bytes

클래스 이름: `ClassDashboardApp`. 이 세 파일은 별도 첨부된 기존 프로토타입이며 현재 클래스레볼루션의 앱 셸이나 모듈이 아니다.

## 2. HTML에 드러난 메뉴

1. 학급점수
2. 학생목록
3. 자리배치도
4. 타임라인
5. 학생관리

공통 하단 액션바에는 전체선택, 선택반전, 선택 인원, 점수 사유 입력, 즐겨찾기/최근 사유, 상점 부여, 벌점 부여가 있다.

## 3. app.js 기능 인벤토리

- 학급점수 대시보드: 학생 아바타 별길, 황금 알, 10단계 진행 트리, 총 학급 점수, 목표와 보상
- 학생목록: 카드형 학생 목록, 상점/벌점/총점 기준 정렬, 랜덤 학생 선택
- 자리배치도: 학생 드래그 앤 드롭, 위치 저장, 랜덤 자리 배치, 모둠별 점수
- 타임라인: 상점/벌점 필터, 대상·사유 검색, 최근 활동 표시
- 학생관리: 학생 추가, 일괄 추가, 번호·이름·상점·벌점·모둠·아바타 수정, 숨김·삭제
- 점수 입력: 여러 학생 선택, 전체선택/선택반전, 사유 입력, 상점/벌점 일괄 부여
- 점수 조정 모달: 숫자 조정, 사유 입력
- 피드백: 상점/벌점별 애니메이션과 학생 아바타 표시
- 사유 관리: 최근 사유와 즐겨찾기 사유
- 배포: `index.html`·`style.css`·`app.js`를 ZIP으로 묶어 다운로드

## 4. 데이터와 계산 로직

학생 필드:
- id, number, name
- positive, negative, total
- group, avatar
- seatingPosition(자리배치도에서 사용)

학급 설정 예시:
- conversionRate: 0.1
- classPositive, classNegative
- totalClassPoints
- 목표 점수와 보상 문구

레거시 수식:
`floor(개인 총점 합계 × conversionRate) + classPositive - classNegative`

주의: 예시 초기 데이터의 학생 총점 합계는 86점이고 conversionRate 0.1, classPositive 50, classNegative 20을 적용하면 38점이다. 소스의 초기 totalClassPoints 값 159와 일치하지 않는다. 따라서 초기 데이터/수식은 참고하되 검증 없이 그대로 이식하지 않는다.

## 5. 저장·기술적 한계

- 학생·활동·설정은 JS 생성자 안의 메모리 상태로 초기화된다.
- 소스에서 localStorage, IndexedDB, 서버 저장 구현을 확인하지 못했다.
- CDN 의존성: JSZip 3.10.1, FileSaver.js 2.0.5, Font Awesome 6.4.0.
- `downloadApp`은 앱 소스 파일을 묶어 다운로드하는 기능이지 학급 데이터 JSON 백업 기능은 아니다.
- 초기 학생 이름/점수/활동은 샘플 데이터다. 실제 사용자 학급 데이터로 취급하지 않는다.

## 6. 클래스레볼루션에 가져올 가치

- 점수 사유의 최근/즐겨찾기
- 학생 일괄 등록과 편집
- 점수 타임라인 및 검색
- 자리배치도와 모둠별 점수
- 학생 랜덤 선택
- 학급 성장 목표와 보상
- 점수 변경에 따른 시각적 피드백

위 기능은 레거시 구현을 그대로 복사하는 대상이 아니다. 현재 사용자 요구와 새 데이터 구조에 맞춰 필요한 항목만 재설계한다.
