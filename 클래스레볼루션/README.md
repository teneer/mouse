# 클래스레볼루션 (Class Revolution)

통합 학급 운영 플랫폼의 초기 구현입니다.

## 프로젝트 기준

- 저장소: `teneer/mouse`
- 작업 브랜치: `class-revolution`
- 작업 폴더: `클래스레볼루션/`
- 데이터: IndexedDB 로컬 우선
- 동일 출처 탭 간 변경 알림: BroadcastChannel + storage event
- 화면: 전체 화면 모드 전환
- 과제 관리: 이번 구현 범위에서 제외

## 모듈

1. `modules/whiteboard/`: 저장소의 `만능칠판-test/`에서 확인한 6.0.0 전자칠판 코드 복사본. 원본 폴더는 변경하지 않음.
2. `modules/scoreboard.js`: 학생 명단, 개인 점수, 모둠 합계의 초기 구현.
3. `modules/growth.js`: 개인 점수 10개 기여가 별길을 채우면 학급점수 1점으로 전환하는 초기 구현.
4. `modules/checklist.js`: 날짜별 학생 활동 기록, 체크/기호/1~5/점수 입력 및 선택적 보상 점수의 초기 구현.

## 데이터 모델

IndexedDB 데이터베이스 `ClassRevolutionLocalDB`에 학급, 학생, 모둠, 점수 이벤트, 성장 상태/전환 이력, 체크리스트 정의/기록, 설정을 저장합니다.

개인 점수 변경은 단일 IndexedDB 트랜잭션으로 학생 점수, 점수 이벤트, 별길 기여를 함께 기록합니다. 별길의 10번째 기여에서 학급 성장 점수 1점을 발생시킵니다.

감점이 이미 적립된 별길 기여를 되돌리는 정책, 학급점수 직접 조정, 되돌리기/수정 이력은 아직 미구현이며 설계 결정이 필요합니다.

## 에셋

- `assets/audio/`: 사용자가 첨부한 MP3 9개와 동일한 바이너리 해시의 저장소 사운드 파일을 복사함.
- `assets/avatars/220/`: 학생 아바타 파일을 배치할 경로로 예약. 사용자 첨부 아바타 ZIP의 원본 PNG는 아직 이 경로에 업로드하지 않음.
- `assets/visuals/`: 별길·나무·배경 스프라이트를 배치할 경로로 예약. 사용자 첨부 이미지 ZIP의 PNG는 아직 업로드하지 않음.

사용자 에셋을 누락 없이 사용하려면 다음 단계에서 원본 ZIP을 보존하고, 이미지 파일을 경로별로 업로드한 뒤 파일명/해상도 매핑표를 작성해야 합니다. 현재 성장 화면은 에셋 경로가 없을 때 CSS 배경 및 아바타 이니셜로 대체 표시됩니다.

## 실행

정적 서버(HTTPS 또는 localhost)에서 `클래스레볼루션/index.html`을 엽니다. ES module과 IndexedDB 사용으로 `file://` 직접 실행은 지원하지 않습니다.

## 현재 구현 상태 및 제한

이 커밋은 실행 가능한 초기 골격과 기본 상호작용을 추가한 단계입니다. 실제 브라우저 검증, 전체 원본 이미지 에셋 업로드, 학생 명부 관리 고도화, 모둠 편집 UI, 점수 사유 즐겨찾기/히스토리/실행 취소, 성장 애니메이션, 체크리스트 통계/보고서/편집·삭제, 전역 피드백 시각/음향 조정은 후속 작업입니다.

전자칠판 복사본은 기존 6.0 기능을 유지하지만, 내부의 기존 점수판 패널은 클래스레볼루션 전체 화면 모드에서 숨겨집니다. 실제 브라우저에서 전자칠판 실행 및 기존 기능 회귀 검증이 필요합니다.
